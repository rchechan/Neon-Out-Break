# VOIDRIDER: RIFT RUN

A native Android cinematic 2.5D arcade campaign. Built for landscape tablets and phones. No internet required and no external graphics engine.

## Gameplay
Pilot a futuristic hovercraft through five collapsing worlds. Dodge electromagnetic barricades, hunter drones and security lasers; collect energy orbs and credits; engage a giant Rift Titan near the end of each mission.

## Controls
- **Left / Right:** on-screen buttons or horizontal swipes
- **Time:** slow the world for an emergency dodge (cooldown)
- **Boost:** faster, temporarily invulnerable flight (uses boost charge)
- **Pause:** top-right

## Progression
Complete sectors to unlock the next. Permanent garage upgrades for engines, hull, chrono core and credit pickup range. Campaign records and credits persist in local Android preferences.

## About
Version 3.0. Offline single-player. Created by AMIR ALI. Source assembled with Gradle 8.9, Java 17 and Android SDK 35. CI produces a debug-signed installable APK in the Actions artifacts section.
